# 1401 1.14.5 for Windows

Bundles NVIDIA driver and Mac app [1.14.5](https://github.com/nullmoth/nvidia-macos-driver/releases/tag/v1.14.5): bounded diagnostic queries, Chromium WebGL initialization and command-buffer lock completion fixes. The Windows application and installer behavior otherwise match 1.14.4. The packaged companion and driver are pinned by SHA-256.

See the driver release notes for validation and remaining limitations. Windows 10/11, 64-bit; macOS 15 Sequoia installer preparation.
