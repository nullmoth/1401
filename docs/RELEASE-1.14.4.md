# 1401 1.14.4 for Windows

**Something not working? [Why a machine does not work, and how to fix it](TROUBLESHOOTING.md) lists every known problem.**

Bundles the NVIDIA driver and Mac app [1.14.4](https://github.com/nullmoth/nvidia-macos-driver/releases/tag/v1.14.4):
a fix for full-screen flicker on machines that copy frames to the screen, and Send logs now includes the AMD / Intel
test driver. Nothing else changed in 1401 since 1.14.3.

## Scope
Windows 10/11, 64-bit. Builds macOS 15 Sequoia installers with OpenCore.
