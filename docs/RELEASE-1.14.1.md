# 1401 1.14.1 for Windows

**Something not working? [Why a machine does not work, and how to fix it](TROUBLESHOOTING.md) lists every known problem.**

Bundles the NVIDIA driver and Mac app 1.14.1, which fixes PCs that stopped starting after the 1.14.0 driver update (their
notes list the details). 1401 itself is unchanged from [1.14.0](RELEASE-1.14.0.md).

## Scope
Windows 10/11, 64-bit. Builds macOS 15 Sequoia installers with OpenCore.
