# Licence request for community driver authors

A short note to send to the authors of the useful projects that have no licence file. Without a licence, copyright law
reserves every right to the author: NullMoth cannot include, download for users, or merge the code, even though it helps
the same people. A one-line LICENSE file fixes that.

Projects with no licence file today: kitsuneislife/nmx-intel, ericek111/vibe-nullmoth-xe3-qemu,
emirercan3459/nullmoth-nvidia-audio, pongpan-bk/First-Custom-iGPU-Driver-for-Intel-Core-5-120U-on-macOS.

## Text

> Hi, and thank you for your work on <project>. Users of NullMoth keep asking about it, and we would like to point them to it
> and, with your permission, build on it with your name on it.
>
> Your repository has no licence file, which means all rights are reserved and nobody, us included, may copy, ship or merge
> the code. Would you add one? Either of these suits us:
>
> - **MIT**: anyone may use and change it as long as your copyright notice stays.
> - **PolyForm Noncommercial 1.0.0** (https://polyformproject.org/licenses/noncommercial/1.0.0): the licence NullMoth itself uses; free for
>   everyone to use and change, not for sale.
>
> On GitHub: Add file, Create new file, name it LICENSE; the "Choose a license template" button offers MIT. Nothing else about
> your project changes, and we will credit you in our NOTICE and in the commit.
>
> If you would rather not, that is fine too: we will only link to your page.

## Notes for the sender

- Each of these projects states or shows that a coding assistant wrote much of it. A licence from the author does not change
  that: we would still read the code for ideas and write our own implementation, unless the author tells us the code is theirs
  to license.
- Put the project name in `<project>` and send one message per author.
