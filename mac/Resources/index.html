Your Mac, mapped

1401 sets up the NullMoth driver on OpenCore Macs running macOS 15.5 or later, or macOS 26 Tahoe. Keep the USB stick or disk OpenCore started this Mac from plugged in: 1401 changes the settings on that one.

Looking...one second

What happens

  1. Get the driver.
  2. Look before touching anything. 1401 reads your OpenCore config and lists every change it would make. Nothing is changed. (macOS asks for your password.)
  3. Install. Backs up your OpenCore config, makes exactly the changes listed, installs the driver, and adds 1401: Remove NVIDIA driver to your boot picker.
  4. Restart. If macOS says a system extension was blocked, open Privacy & Security, click Allow, and restart once more.

What 1401 is doing

Updates


1401 checks for the newest NullMoth driver and the newest 1401 app. The app updates itself and reopens. The driver is downloaded, checked against its published SHA-256 and installed the same way as above, with your OpenCore config backed up first.


   


Early updates. A new driver goes first to people who turn this on, and reaches everyone once their machines show it made nothing worse. Turn it on to get releases a day or two early and send logs when something is off.


  



Update to macOS 26 Tahoe


From macOS 15, Prepare this Mac for Tahoe installs or updates the driver, parks it, and gives the installer the small GPU BAR it needs so its screens show. Then install macOS 26 from Software Update; the first start after the update sets the driver up for Tahoe and restarts once by itself. Cancel the Tahoe preparation puts everything back.


   



If something goes wrong after you restart


In the OpenCore boot picker choose 1401: Remove NVIDIA driver, then your macOS disk. 1401 removes the driver and restarts, and this Mac comes back as it was before the install, OpenCore config included. The screen may stay dark until that second restart.









Check my EFI


Checks the OpenCore setup this Mac starts from against the settings that work on PCs like yours, and explains anything that needs changing, with the steps. It only reads: nothing is changed. Asks for your password once.













Tools


Mount EFI


The EFI partition holds your boot setup. 1401 finds the one this Mac started from, mounts it and opens it in Finder. Asks for your password once.


 


Startup text (verbose mode)


Shows what macOS is doing while it starts instead of the Apple logo. Useful if a start hangs. Takes effect at the next restart.


 


Built-in screen brightness (laptops)


For a laptop whose built-in screen is wired to the NVIDIA GPU (MUX set to Discrete or dGPU). It lets the driver read the panel's brightness controls from the laptop's firmware. It is off by default because that call stopped some PCs at GPU start; if yours stops there, choose 1401: Start once without NVIDIA driver in the boot picker and turn it off here.


 


HiDPI (Retina) modes


Lets HiDPI "looks like" sizes work, for example 1920 x 1080 on a 2560 x 1440 screen, including ones added with a tool such as BetterDisplay. Without it such a size is refused and switches back. The driver draws the desktop at up to twice the screen's size, which uses more video memory. Takes effect at the next restart.


 


Automatic login


1401 turned on automatic login so this Mac could reach the desktop while the driver was missing. That stores your password in a form anyone who can read the disk can recover. Once the driver works, turn it off.




Hybrid laptop (the built-in screen runs on the Intel or AMD processor graphics)


Most gaming laptops wire the built-in screen to the graphics in the processor, so the NVIDIA card has nothing to draw it on. This installs a panel driver beside the NVIDIA driver (the Intel one on Intel graphics, the AMD one on a Ryzen with Radeon graphics): the NVIDIA card does the rendering and each finished frame goes to the screen through the processor graphics. On Ryzen laptops turn the OpenCore Fix PAT patch off first (docs/HYBRID-LAPTOPS.md); only copy is available there. Copy works on Intel 11th generation and newer; scan out in place is the faster level for 12th and 13th generation. It has not run on a hybrid laptop yet, so your Send logs are how it gets fixed. It needs the NVIDIA driver already installed and the driver package checked above.


If the screen stays dark, choose 1401: Start once without NVIDIA driver in the boot picker and turn it off here. Turning it off also takes the panel driver out again.


   


Drives behind Intel VMD or RAID


macOS can only use drives the firmware shows as plain AHCI or NVMe disks. This PC has Intel VMD or RAID storage, so its internal drives may be hidden from macOS. Two ways round it:


Install on an external drive. Plug in a USB SSD (or an SSD that is not behind VMD) and install macOS on it from the 1401 stick. The internal drive and Windows are not touched. In 1401 for Windows tick Install macOS on an external drive before you build.


Turn VMD off. In 1401 for Windows the build shows the BIOS path for your board and offers Prepare Windows, Finish and Undo: Prepare makes a restore point, pauses BitLocker and sets the standard drivers, you switch VMD off in the BIOS, Finish returns Windows to a normal start, and Undo puts every value back. These steps run on Windows only, so this app only explains them.

GPU boost


Holds the NVIDIA card at its maximum clocks while this is on, for work that is limited by the GPU's idle-to-busy ramp-up. It costs power and heat, so it is off until you turn it on. It installs a small background job from the checked driver package; the package's file list is verified before anything runs as root. Turning it off stops it holding the boost; Remove takes the job off this Mac.


    


Ryzen laptop power profile


A Ryzen laptop runs at the processor's default power limits, which are loud and hot on a battery. This sets a quieter profile (by default 13 W sustained, 14 W slow, 15 W fast, 70 °C; change the limits below before you turn it on) through NullMoth's RyzenAdj build. It installs a small kernel extension that can talk to the processor's power controller only after you turn this on, and a job that runs as root. It is off until you choose it.


If anything goes wrong, turn it off here: that removes the job, the kernel extension and the boot setting.


Watts: sustained  slow  fast    Temperature limit  °C (watts 5 to 65, sustained at most slow at most fast; temperature 50 to 100)


  


AMD / Intel GPU and NPU driver (test)


For the AMD and Intel GPUs macOS has no driver for (Ryzen APUs, Radeon RX 7000/9000, Intel Iris Xe and Arc graphics), and the NPU in Intel Core Ultra and AMD Ryzen AI processors. An early test build: your Send logs are how it gets fixed. It downloads only the firmware your GPU and NPU need from linux-firmware (every file checked) and takes effect at the next restart.


If that GPU drives your screen, the screen can stay dark. Then choose 1401: Start once without NVIDIA driver in the boot picker (it parks this driver too) and turn it off here.


 


Test program. While the test driver is on, 1401 sends a short report after every restart: the driver's kernel messages, any crash, and which GPU and build you have (names and serial numbers removed). Leave at any time.


  


Intel Xe graphics (WhateverXe, test)


For Tiger Lake, Alder Lake and Raptor Lake Intel graphics on macOS 15.8 or 26.7 and later. It uses WhateverXe by b00t0x: 1401 adds it to OpenCore, you restart, then press Turn it on again to install its graphics package. Those parts come straight from the author's GitHub, each checked. WhateverGreen is turned off while it is on; Turn it off puts everything back.


If the screen stays dark after the restart, choose 1401: Start once without NVIDIA driver in the boot picker: that start also leaves WhateverXe off. Then turn it off here.


 


Game Mode


While a game is in front and full screen, this gives it the processor first, holds back background indexing and other apps' use of the graphics card, and puts everything back when you leave the game. A game controller shows in the menu bar while it is on. It stays off until you turn it on, and turning it off removes it.


  


Microphone and camera


With the driver installed, macOS does not ask before an app uses the microphone or camera, so apps such as Discord get silence and never appear under Privacy & Security. Pick the app here to allow it the microphone, camera and screen recording.


 


Driver settings


HDR, 10-bit colour, variable refresh, colour range, scaling, surround, frame-rate limit and more, with your GPUs' link and memory facts. Every change is shown in full and asked for first.




Map my GPU (experimental)


A few minutes of measurements on this Mac's GPU: what Metal reports, a correctness check, memory and compute speed, and small test shaders. Nothing is changed and no display mode is touched. The result goes in the log folder, and Send logs uploads it so the next driver can be tuned for your card.


 


ARM apps (opt-in)




 Not now


Apps built only for Apple silicon can be translated to run on this Mac. An iPhone or iPad app you built yourself (an .ipa that is not App Store encrypted) is first made into a Mac app, then translated. Translation takes minutes for a small app and up to an hour or more for a big one. The original app is never changed: the translated copy goes to Applications > NullMoth ARM. Turning this off removes the translator and the translated copies, and your 2.7 driver keeps working.


    






 




Homebrew


Two Homebrews side by side, as on a Mac with Apple silicon: the ARM one in /opt/homebrew installs Homebrew's Apple-silicon packages and translates them for this Mac; the Intel one in /usr/local runs natively but mostly builds from source, because Homebrew stopped publishing Intel packages. In Terminal, abrew is always ARM, ibrew always Intel, and brew is the one you pick here.

Something still wrong?


Send logs


1401 sends what it did, the driver's state, crash reports, OpenCore's startup logs and a numeric device map, with names, serial numbers and addresses removed. You get a report ID to post in the NullMoth Discord.


If the driver could not translate a shader, up to 24 of those shaders (at most 4 MB, from the apps you ran) are attached so the failure can be reproduced. They are sent only when you press the button. To stop the driver keeping them, create the empty file /Library/GPUBundles/nvmtl/no-failed-air.


 


Record the flicker: press it while the screen flickers. 1401 records 20 seconds of how the driver puts frames on the display and sends it with your logs.




Crash report


If the driver ever crashes this Mac, 1401 asks at the next login whether to make a report. It is a text file on your Desktop with your hardware and what failed, with your name, your Mac's name, serial numbers, addresses and file paths taken out. 1401 never sends it by itself.




   


Optional diagnostics


Capture is unavailable in this version. Send logs still collects hardware, kernel and panic evidence. No security settings have changed.
