## C. 代码层未修复项（已审计、记录）

| 项 | 风险 | 建议 |
|---|---|---|
| `apple.download` 跨进程续传 | 恢复镜像下载中断后重来 | 在 `.part` 存在时校验完整前缀并从最后完整块续传 |
| `verify_xar` 不验 Apple 签名/跳过无校验和条目 | 结构完整 ≠ Apple 认证 | Windows 上明确标注“结构校验”；在 macOS 上用 `pkgutil --check-signature` |
| Recovery 元数据未绑定 macOS 版本 | 理论上可被替换为另一份 Apple 签名镜像 | 将 `AP`/board 与请求 Darwin 绑定；本地镜像支持 `product.json` 已实现 |
| EFI/脚本文本读回未绕过缓存 | 极端情况下读回通过但盘未落盘 | 对 EFI 文件也使用 `FILE_FLAG_NO_BUFFERING` 或写后 `FlushFileBuffers` |
| WMI 回退分区类型检查较弱 | 可识别的 Windows 恢复分区可能不触发第二次确认 | 在 WMI 路径补充分区类型/GPT GUID 查询 |
| 提权 WebBrowser 渲染用户可写 HTML | 同用户进程可替换页面 | 页面写入管理员目录/禁用脚本/哈希校验 |

| `Engine.Run` 无超时/取消 | 下载/PowerShell 卡住时 UI 无法取消 | 进程树 job + 取消按钮 + 超时 |
| 启动时同步读取 U 盘文件 | 恶意/超大文件可卡 UI | 单文件上限 + 异步 |
| `storage_prep` 子进程无超时、回滚日志不准确 | BitLocker/BCD 命令卡住 | 加超时并记录真实回滚结果 |
| 无 `packages.lock.json`、MSVC 版本未固定 | 构建字节不完全可复现 | 锁定 NuGet/MSVC；记录编译器版本 |

## E. 环境限制

- 当前 Windows 会话非管理员：无法读取 `\\.\PhysicalDriveN`，无法验证真实盘身份读取；应用本身以管理员清单运行，生产路径具备权限。
- 无符号链接权限（WinError 1314）：2 个安全检查用例显式 skip；非符号链接分支仍运行。
- 网络对部分 GitHub 主机的证书链不稳定：已用 `truststore` 在项目 venv 内解决；生产引擎的 `p1401.tls` 同时使用 OS 存储与 certifi。
- 真实 macOS 环境不存在：所有“安装/启动/图形/网络/输入/睡眠”结论均为待实机验证。
