# 源码、依赖与调用链审计

基线：`v2.9` = `03c79ef772f6142d59eb5203ce0efa98845bd0ba`（官方 Release `v2.9` 的 `target_commitish` 核对一致）。

## 2. Python 引擎核心模块（按职责）

- 入口：`p1401/__main__.py`（`plan`、`build`、`acpi-bundle`、`storage-prep`）；各步骤也可 `python -m p1401.<module>` 单独运行。
- 扫描：`scan.py`、`hwcapture.py`、`scan_evidence.py`、`probe_report.py`、`report.py`、`devicemap.py`。
- 构建：`engine.py`（驱动上游 OCPE、回答所有交互问题、应用策略）、`policy.py`、`efi_rules.py/json`、`machine_recipes.json`、`known_machines.json`、`huawei.py`。
- 硬件规则：`intel_gpu.py`、`amd_gpu.py`、`amd_rdna4.py`、`community.py`、`community_gpu.py`、`netsupport.py`、`utbmap.py`、`peripheral_caps.py`、`acpi_*.py`、`bootfix.py`、`panel_guard.py`、`storage_drives.py`、`storage_prep.py`、`identity_ready.py`。
- Recovery：`apple.py`（Apple Internet Recovery、chunklist 签名与逐块 SHA-256）、`fullinstaller.py`（InstallAssistant.pkg 目录/下载/XAR 校验）、`downloads.py`、`mirror.py`、`mirror_metadata.py`、`archive_download.py`、`tls.py`、`release_sig.py`。
- 写盘：`usbwriter.py`（安全闸门与流程）、`rawdisk.py`（原始扇区擦除）、`fullinstaller.py`（第二分区）、`machine_handoff.py`、`nullmoth.py`。
- 校验/诊断：`validate.py`（ocvalidate + 文件级不变量）、`efidoctor.py`、`diagnose.py`、`job_guard.py`、`policy.py`。

## 4. 调用链（真实路径）

```
1401.exe (WinForms)
  └─ Engine.Run("p1401.<module> ...")  独立进程、-E -s -X utf8 -B
      ├─ p1401.scan      → Hardware Sniffer + ACPI dump → Report.json + ACPI/
      ├─ p1401 build     → upstream OCPE（逐问题规则回答）→ policy.apply → validate.validate
      │                    → EFI/OC/config.plist + Kexts + ACPI + Drivers
      ├─ p1401.guide     → BIOS 步骤 HTML
      └─ p1401.usbwriter write
           ├─ list_disks / refind / eligible / check_script
           ├─ validate.validate（擦盘前再次校验 EFI）
           ├─ rawdisk.wipe_mbr_fat32（内部身份复核）或 diskpart 回退
           ├─ apple.preflight / download 或 local_image→verify_local→copy_local
           ├─ EFI 复制 + 读回校验
           └─ fullinstaller（可选第二分区）
```

## 5. 依赖与可复现性风险

| 风险 | 现状 | 影响/处置 |
|---|---|---|
| .NET SDK 版本 | `global.json` 固定 `8.0.425`，`rollForward: disable` | 本机安装在项目内 `.dotnet/`，未改系统 PATH；任何其他 SDK 都会失败 |
| NuGet | `NuGet.Config` 仅 nuget.org；`Microsoft.NETFramework.ReferenceAssemblies 1.0.3` | 首次构建需要网络；无 `packages.lock.json` |
| Python 运行时 | 发布包固定 `3.13.17`（`windows/release-inputs.json`）；开发用 3.12.10 | 开发/打包解释器不同，已分别跑测试 |
| OpenCore 版本 | 引擎运行时从 Dortania `latest.json` 取当前版本（本次为 1.0.9）；`windows/release-inputs.json` 另固定 1.0.8 的包基线 | 构建结果与 `ocvalidate` 同版本（本次 1.0.9，0 问题）；离线复现需缓存 |
| 依赖下载 | OpenCore、kext、iasl、baseline zip、驱动包运行时下载，SHA-256/签名校验 | 网络阻断会失败并给出原因；不是完全离线构建 |
| 预编译/外部工具 | `acpidump.exe` 固定哈希；`macserial.exe` 随上游；MSVC 版本未固定 | 原生辅助产物可能随编译器漂移；发布验证记录哈希 |
| 许可证 | PolyForm 非商业 + 第三方各自许可 | 不得商业分发；`tests/test_licenses.py` 覆盖 |
| 目录结构 | 保留官方原结构；新增 `p1401/huawei.py`、`scripts/`、`reports/` | 未重构上游源码 |

## 6. 审计方法

- 逐文件阅读 `p1401/` 与 `windows/App/`，交叉核对 `docs/HOW-IT-WORKS.md`、README、CHANGELOG。
- 用 `tools/machine_replay.py`/真实扫描报告验证硬件选择路径。
- 用 `gh` 枚举 81 个 Release、157 个 Issue（132 开/25 闭）、6 个 PR、全部分支，确认 v2.9 之后无上游修复可同步。
- 所有结论落在 `reports/bugs/` 与 `reports/hardware/`，并尽量以测试或真实构建结果证明。
