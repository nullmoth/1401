## 4. 本机环境问题与处置

| 问题 | 现象 | 处置 |
|---|---|---|
| 未提权 | `\\.\PhysicalDriveN` 打开返回 Windows error 5；`Confirm-SecureBootUEFI` 拒绝访问 | 只做只读扫描/构建/模拟测试；真实写盘和物理盘身份读取保持未执行 |
| 符号链接权限 | `os.symlink` 报 WinError 1314 | 相关安全测试拆分为独立用例并在缺少权限时明确 skip（不是通过）；其余用例照常运行 |
| Python TLS 证书链 | 部分 GitHub/下载主机报 `unable to get issuer certificate` | 项目 venv 安装 `truststore` 并注入 Windows 证书存储；官方 `p1401.tls` 本身也加载 OS 存储 + certifi |
| 依赖缓存 ACL | `%LOCALAPPDATA%\NullMoth\1401\OCK_Files\Lilu` 拒绝访问，重复构建报 PermissionError | 已修复：`cache_writable()` 检查根目录及子目录，`pick_cache()` 回退到 `OCK_Files-2/3`；本次构建实际使用 `OCK_Files-2` |
| 权限不足的 PowerShell 存储 cmdlet | 本机 `Get-Disk` 正常；未触发回退 | 回退路径由单元测试覆盖 |

## 6. 复现步骤

```powershell
# 1) 项目内 SDK（一次性）
powershell -ExecutionPolicy Bypass -File .dotnet-setup\dotnet-install.ps1 -Version 8.0.425 -InstallDir .dotnet -NoPath
# 2) Python 环境（一次性）
py -3.12 -m venv .venv
.\.venv\Scripts\pip install pywin32==312 WMI==1.5.1 certifi truststore
# 3) 构建
.\.dotnet\dotnet.exe build windows\App\App.csproj -c Release -o build\1401-compiled-291
# 4) 测试
scripts\run-tests.cmd
```

本机没有进行系统级安装，因此上述步骤不会修改全局 PATH、注册表或系统驱动。
